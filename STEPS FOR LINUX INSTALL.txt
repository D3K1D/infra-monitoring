========================================================================
STEPS FOR LINUX INSTALL  -  Server build for Senior Project + Personal Cloud
Last updated: 2026-06-30
========================================================================

GOAL
  Turn the old desktop into a headless Ubuntu server that runs:
    1. The capstone monitoring stack (FastAPI backend, MySQL, dashboard,
       self-monitoring agent).
    2. A personal cloud (Nextcloud) for remote drone-business photos/video.
  Storage = two 4TB NAS drives mirrored with RAID 1 (4TB usable, survives
  one drive failure).

  NOTE: RAID 1 is NOT a backup. It protects against a drive dying, not
  against accidental deletion, ransomware, or theft/fire. Keep a separate
  copy of your most important drone files somewhere off this machine.


========================================================================
PART 1  -  DRIVES TO BUY  (get TWO identical drives)
========================================================================
Buy two of the SAME model so the mirror is balanced. All options below are
NAS-rated and CMR (correct for RAID). Do NOT buy SMR drives or USB externals.

OPTION A - Seagate IronWolf 4TB (ST4000VN006)  [recommended]
  256MB cache, 5400 RPM, 3-yr warranty + 3 yrs data recovery service.
  https://www.amazon.com/Seagate-IronWolf-ST4000VN006-Hard-Drive/dp/B09RMRKC9P
  Alt listing: https://www.amazon.com/Seagate-IronWolf-Internal-Hard-Drive/dp/B09NHV3CK9

OPTION B - WD Red Plus 4TB (WD40EFPX)  [recommended]
  256MB cache, 5400 RPM, has TLER (built for RAID), 3-yr warranty.
  https://www.amazon.com/Western-Digital-Plus-Internal-Drive/dp/B0BDXSK2K7

OPTION C - WD Red Plus 4TB (WD40EFZX)  [also fine, 128MB cache version]
  https://www.amazon.com/Western-Digital-Plus-Internal-Drive/dp/B08VH8C3WZ

Pick ONE option, buy TWO of it. Budget ~$180-240 for the pair.
Tip: check https://diskprices.com/ for live cost-per-TB before ordering.

BEFORE YOU BUY - confirm the old desktop has:
  - 2 free SATA data ports on the motherboard (plus the system drive = 3 total)
  - 2 free SATA power connectors from the PSU (SATA power splitter is cheap if not)
  - 2 free 3.5" drive bays (or use adhesive/zip-tie mounting in a pinch)

ALSO GRAB:
  - One USB flash drive, 4GB or larger (for the installer; it gets erased)


========================================================================
PART 2  -  MAKE THE INSTALLER USB
========================================================================
1. On your Windows dev desktop, download Ubuntu Server 26.04 LTS ISO:
     https://ubuntu.com/download/server
     (Get the "Ubuntu Server" ISO, NOT Ubuntu Desktop.)
2. Download Rufus (https://rufus.ie) or balenaEtcher (https://etcher.balena.io).
3. Insert the USB flash drive.
4. In Rufus: select the USB device, select the Ubuntu ISO, leave defaults,
   click START. Wait until it finishes. This USB is now your installer.


========================================================================
PART 3  -  INSTALL THE DRIVES (power OFF, unplugged)
========================================================================
1. Shut down the old desktop, unplug power, hold the power button 5s to drain.
2. Open the case. Touch bare metal first to discharge static.
3. Mount the TWO new 4TB drives in bays. Connect each to a SATA data port and
   a SATA power lead. Leave the existing system drive connected too.
4. (Optional but helpful) Note which physical drive is on which SATA port.
5. Close up, reconnect power and a monitor + keyboard for the install.


========================================================================
PART 4  -  INSTALL UBUNTU SERVER 26.04 LTS
========================================================================
1. Insert the installer USB, power on, and open the boot menu (usually F12,
   F11, F2, or DEL during the logo - depends on the motherboard).
2. Boot from the USB. Choose "Try or Install Ubuntu Server".
3. Follow the installer:
     - Language / keyboard: your choice.
     - Network: it should auto-grab an IP over Ethernet. Note the IP shown.
     - Proxy / mirror: leave blank / default.
     - STORAGE - IMPORTANT:
         * Install Ubuntu ONLY on the SYSTEM drive (the old original drive).
         * Do NOT select or format the two new 4TB drives here. Leave them
           alone - we build the RAID array after install in Part 6.
         * If unsure which is which, the two new drives are the matching 4TB
           pair; the system drive is the odd one out.
     - Profile: set your name, a server name (e.g. "monitor-server"),
       username, and a strong password. Remember these.
     - "Install OpenSSH server": CHECK THIS BOX (lets you manage it remotely).
     - Featured snaps: skip them all.
4. Let it install, then "Reboot Now" and remove the USB when prompted.
5. Log in at the console with the username/password you set.


========================================================================
PART 5  -  FIRST LOGIN, UPDATES, REMOTE ACCESS
========================================================================
1. Update everything:
     sudo apt update && sudo apt upgrade -y
2. Find this server's IP address:
     ip a            (look for the 192.168.x.x address under your ethernet device)
3. From now on you can manage it remotely from any LAN machine:
     ssh YOUR_USERNAME@192.168.x.x
4. SET A STATIC IP (so the address never changes):
     Easiest: log into your router, find this server in the DHCP client list,
     and create a "DHCP reservation" tying its MAC address to a fixed IP.
     (This is simpler and just as reliable as editing netplan on the server.)


========================================================================
PART 6  -  BUILD THE RAID 1 MIRROR (the two 4TB drives)
========================================================================
1. Install the RAID tool:
     sudo apt install mdadm -y
2. List drives and identify the two new 4TB disks (e.g. /dev/sdb and /dev/sdc).
   The system drive is usually /dev/sda - DO NOT touch it.
     lsblk
     sudo fdisk -l        (confirm sizes; the two 4TB ones are the new drives)
3. Create the mirror (replace sdb/sdc with YOUR two new drives):
     sudo mdadm --create --verbose /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc
   (Type "y" if it warns about no partition table.)
4. Watch it sync (can take a few hours - it works in the background):
     cat /proc/mdstat
5. Make a filesystem on the array:
     sudo mkfs.ext4 /dev/md0
6. Mount it:
     sudo mkdir -p /mnt/data
     sudo mount /dev/md0 /mnt/data
7. Save the RAID config and make the mount permanent so it survives reboots:
     sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
     sudo update-initramfs -u
     echo '/dev/md0  /mnt/data  ext4  defaults,nofail  0  0' | sudo tee -a /etc/fstab
8. Verify after a reboot:
     sudo reboot
     (log back in)  ->  df -h     (you should see /mnt/data with ~3.6TB free)

  YOUR MIRRORED STORAGE IS NOW AT:  /mnt/data


========================================================================
PART 7  -  DEPLOY THE CAPSTONE MONITORING STACK
========================================================================
(High level - we will do this together step by step once the server is up.
 The project already runs end-to-end on the dev desktop; this moves it over.)
  1. Install MySQL server + Python 3:
       sudo apt install mysql-server python3-venv python3-pip git -y
  2. Copy the project to the server (git clone, or scp the project folder).
  3. Load the schema:  mysql < database/schema.sql
  4. Create the backend .env (DB creds, SECRET_KEY, AGENT_API_KEY).
  5. Create a venv, pip install -r requirements.txt.
  6. Run the FastAPI app (later as a systemd service so it auto-starts).
  7. Open the firewall for the app port:  sudo ufw allow 8000
  8. Point the self-monitoring agent at http://localhost:8000.
  -> Ping me when you reach this part and I will give exact commands for your setup.


========================================================================
PART 8  -  PERSONAL CLOUD (NEXTCLOUD) FOR DRONE MEDIA
========================================================================
(Personal goal, separate from the school project. Easiest install = snap.)
  1. Install:
       sudo snap install nextcloud
  2. Point Nextcloud's data at the RAID array so media lands on the mirror:
       (we will set the data directory to /mnt/data/nextcloud during setup)
  3. Create your admin account:
       sudo nextcloud.manual-install ADMIN_USER ADMIN_PASSWORD
  4. Allow your server's IP/hostname as a trusted domain, then open it in a
     browser on the LAN:  http://192.168.x.x
  5. REMOTE (internet) ACCESS - pick one when you get there:
       - Tailscale (easiest, no router config): access from anywhere on a
         private mesh VPN. Install on server + phone/laptop.
       - Cloudflare Tunnel: gives a public https address, no port-forwarding.
       - Router port-forward + dynamic DNS: more exposed, needs HTTPS/care.
  -> We will choose and configure this together; do NOT expose it to the
     internet without HTTPS.
